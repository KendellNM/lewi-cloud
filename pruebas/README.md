# Pruebas T01–T17

Una carpeta por prueba con su especificación (`README.md`) y un `run.sh` por completar. Resultados en `evidencias/`.
Orden recomendado: T01–T02, T03, T05, T06–T07, T12, T09, T08, T11, T04, T10, T13, T14, T15, T16, T17. Los fallos se ensayan de uno en uno y se restaura el estado base entre pruebas. Se detiene la prueba si peligra la integridad o no se puede confirmar un único escritor.
