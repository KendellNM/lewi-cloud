# costos/ (agente 11)

- `cotizacion.md`: cotización oficial por proveedor (fecha de consulta, tarifas, supuestos, horas).
- `consumo-real.md`: costos observados tras las sesiones (de las consolas de facturación) y recursos residuales.

Fórmula: costo bruto = cantidad × horas facturables × tarifa + almacenamiento + operaciones + transferencia + IP públicas. Costo neto = bruto − créditos confirmados.
